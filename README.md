### Hi, I'm bobslayerX 👋

I build open-source tools for **crypto investigations** — following stolen funds
across blockchains and turning the trail into evidence people can act on.

🔍 **[crypttrace](https://github.com/bobslayerX/crypttrace)** — OSINT toolkit for tracing stolen crypto
on Ethereum, Bitcoin, Tron and Solana

- traces funds to exchanges, mixers and bridges, and spots exchange deposit addresses
- checks whether stolen USDT/USDC is still at an address and who can freeze it
- detects address-poisoning attacks, from the victim's side and the attacker's
- writes a one-page HTML case file for exchanges and police
